Integrate

SDK (TypeScript)

@findaro/sdk is a headless, typed client for search and streaming chat. Zero dependencies, ESM + UMD, about 1.5 KB gzipped. Use it when you want your own UI.

Install

The SDK isn't published to npm yet. Build it from the repository and use the files in packages/sdk/dist/ (findaro-sdk.mjs, findaro-sdk.umd.js and type declarations):

git clone __GITHUB_URL__ findaro && cd findaro
npm install && npm run build

In a monorepo you can depend on the package by path, e.g. "@findaro/sdk": "file:../findaro/packages/sdk".

Create a client

import { createClient, debounce } from "@findaro/sdk";

const findaro = createClient({
  projectId: "prj_…",
  searchKey: "fdr_search_…",   // browser-safe; never an admin key
  baseUrl: "__API_URL__",
});

Search

const res = await findaro.search("kaale joote 1000 ke andar");   // typed SearchResponse
res.total;
res.hits;                    // [{ id, score, document, highlights }]
res.understood?.chips;       // [{ label: "Under ₹1,000", remove: [...] }, { label: "Black", remove: [...] }]
res.pills;                   // refinement choices for the current results
res.display;                 // which fields hold title, price, image, rating, currency

// remove a chip without a new natural-language query
await findaro.search({ query: res.query, patch: res.understood!.chips[1].remove });

// explicit filters, sort, facets
await findaro.search({ query: "kurta", filters: { price: { lte: 1500 } }, sort: "price:asc", facets: ["color"] });

// search-as-you-type: debounce, and skip the LLM planner while typing
const typeahead = debounce((q: string) => findaro.search({ query: q, llm: false }), 250);

Chat

chat() returns a stream you can iterate, attach callbacks to, or await as a whole.

// iterate events
const turn = findaro.chat("saree under 1000", { sessionId });
for await (const ev of turn) {
  if (ev.type === "results") showProducts(ev.data.items);
  if (ev.type === "text") appendText(ev.data.delta);
}
const { sessionId: next, clarify } = await turn.result;

// or callbacks
findaro.chat("sasta wala", { sessionId: next, onText: (_, full) => render(full) });

// pick a clarifier chip: send its label as the message and its patch
findaro.chat(chip.label, { sessionId: next, patch: chip.patch });

Ask about a product

Pass productIds (up to 3) and every turn is answered about those products, like a product page. Facts from the listing are in text; labeled general know-how is in general.

const about = await findaro.chat("Is this made in India?", { productIds: ["FW-00421"] }).result;
about.text;      // from the listing only
about.general;   // optional general advice: show it labeled as such

Chat events

EventWhenPayload
sessionfirstsession_id, turn
planalwaysunderstood; delta (turn type, chips added/removed)
resultsbefore any textitems, total, facets, pills, display, match_quality, close_matches
clarifyoptional, at most onequestion, chips each with a patch
textstreameddelta; part is answer or general
donelasttimings, turn_type, reason, answer_source

Behaviour

  • Cancellation: a new search() (or chat()) cancels the client's previous in-flight one. Pass { cancelPrevious: false } to keep it, or your own signal.
  • Retries: network errors are retried once.
  • Errors: API errors throw a FindaroError with status and code.
  • Types: generated from the API's OpenAPI spec, so they match the API reference.
