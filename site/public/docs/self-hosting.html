Run it yourself

Self-hosting

findaro is open source under Apache-2.0. The whole stack runs with docker compose: the API, an ingest worker, OpenSearch, Postgres and Redis. The repository's README is the full reference; this page is the short version.

Requirements

  • Docker, with about 4 GB of memory for containers.
  • Optional: Ollama for the AI parts (query planner and chat). Without it, search works fully and chat answers fall back to plain one-line templates.
  • To build the widget and SDK: Node.js 20 or newer.

Run it

git clone __GITHUB_URL__ findaro && cd findaro
export FINDARO_BOOTSTRAP_TOKEN=$(openssl rand -hex 24)   # required anywhere others can reach the API
docker compose up -d --build                            # API on :8000, worker, OpenSearch, Postgres, Redis
curl -s localhost:8000/healthz                          # {"status":"ok"} once it's up

# optional, for the AI parts
ollama pull llama3.2:3b    # query planner
ollama pull llama3.1:8b    # chat answers

Then follow the quickstart from “Self-hosted”. For a demo with a synthetic catalog, run uv run python scripts/demo_setup.py and open the demo page on port 8080.

Production deployment

Deployment files for running findaro on a server live in the repository's deploy/ directory. Whatever you use, check these:

  • Set FINDARO_BOOTSTRAP_TOKEN. Without it anyone who can reach the API can create projects.
  • Set FINDARO_ALLOW_LOCALHOST_ORIGINS=false so localhost origins aren't accepted for search keys.
  • Put the API behind HTTPS.
  • Run a single ingest worker; jobs for a project run in order.
  • The query log (FINDARO_QUERY_LOG) records end-user queries. It's on in the dev compose file; decide on retention or turn it off (set it empty).

Configuration

All settings are environment variables prefixed FINDARO_. The ones you're most likely to touch:

VariableDefaultWhat it does
FINDARO_BOOTSTRAP_TOKENunsetToken required to create projects.
FINDARO_ALLOW_LOCALHOST_ORIGINStrueAccept localhost origins for search keys (development).
FINDARO_RATE_LIMIT_PER_SECOND50Requests per second per key.
FINDARO_PLANNER_PROVIDER / FINDARO_PLANNER_MODELollama / llama3.2:3bLLM for the query planner. anthropic is supported (paid, needs a key).
FINDARO_PLANNER_TIMEOUT_MS800How long search waits for the planner before using the rules plan.
FINDARO_CHAT_PROVIDER / FINDARO_CHAT_MODELollama / llama3.1:8bLLM for chat answers. openai, anthropic (paid) or none.
FINDARO_LOCALE_PACKSen,hi-enLanguage packs for query understanding.
FINDARO_QUERY_LOGunset (compose: on)Path of a JSONL log of searches and chat turns.

Paid LLM providers are never switched on by an API key alone: you have to set the provider explicitly. The full list of settings is in src/findaro/config.py.
