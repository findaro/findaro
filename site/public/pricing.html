Billing questions

What counts as a search?

Submitted searches plus chat turns. Each /v1/search request counts, and each message in the AI chat counts as one. Search-as-you-type requests the widget sends while someone types ("llm": false) don't count.

What happens if we go over a limit?

Going over a limit never cuts your search off without warning. We'll contact you first and talk about whether a different plan fits.

How does billing work during the beta?

Monthly, by invoice. There's no card form on this site. Request access, tell us which plan you're interested in, and we'll set things up with you directly.

INR or USD?

Both are shown so you can compare. Use the toggle at the top; we'll confirm the invoicing currency with you when we set up your account.

Is the open-source version limited?

No. It's the same engine under Apache-2.0, free forever. You run and scale it yourself, and the AI chat uses whichever LLM you configure (a local Ollama model by default).

Not sure which plan fits?

Tell us your catalog size and expected traffic. We'll suggest one.
